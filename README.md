# Mohammad Arkam: Portfolio site

Static site (index.html). No build step.

## Deploy on Vercel
1. Create a GitHub repo (e.g. `portfolio`) and upload these files.
2. Go to vercel.com, click Add New, then Project, and import the repo.
3. Framework Preset: Other. Leave build settings empty. Click Deploy.
4. Copy your live address (e.g. https://portfolio-xxxx.vercel.app).
5. In index.html, replace both `YOUR-SITE.vercel.app` values (og:image and og:url) with your real domain. Commit. Vercel redeploys automatically.
6. Force LinkedIn to refresh the preview: linkedin.com/post-inspector, paste your URL, click Inspect.

Optional: Project Settings, then Domains, to rename it to something like arkam-portfolio.vercel.app.
